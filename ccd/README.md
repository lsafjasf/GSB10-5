# CCD — 连续碰撞检测（Python 3，仅标准库）

解决“每帧位移大于自身尺寸 → 帧末离散检测直接穿透”的问题：
不看帧末快照，而是在整个帧区间 `[0, dt]` 上求**首次接触时刻（TOI）**。

## 文件

| 文件 | 内容 |
|---|---|
| `ccd.py` | 库：圆/AABB 的扫掠检测 + 一帧内多碰撞时序模拟 |
| `test_ccd.py` | 16 个单元测试（静止/慢速/高速穿透/恰好相切/多碰撞排序） |
| `verify.py` | 对拍：解析解 & 极小步长参考解，误差表，事件序列演示 |
| `bench.py` | 10 万次移动的耗时与内存峰值 |

## 检测方法：扫掠解析法（swept analytic test）

设帧内归一化时间 `t ∈ [0,1]`，位置 `p(t) = p0 + v·(t·dt)`。

- **圆-圆**：相对位置 `r0`、相对位移 `u = (vA−vB)·dt`、半径和 `R`，
  解二次方程 `|r0 + t·u|² = R²`，即 `a t² + b t + c = 0`：
  - 判别式 `D < 0` → 最近距离仍大于 R，错过；
  - `D = 0`（重根）→ **恰好相切**，报 `TOUCH`（擦边，不算碰撞）；
  - `D > 0` → 小根 `t = (−b−√D)/(2a)` 为进入时刻，报 `COLLIDE`；
  - `c < 0` → 帧首已重叠，报 `OVERLAP`。
- **圆-AABB**：相对射线 vs 盒膨胀半径后的 Minkowski 和 =
  面区域（slab 射线法）+ 4 个圆角（圆-点扫掠），两类候选取最早者，
  角部结果精确而非保守近似。
- **一帧多次碰撞**（`simulate`）：反复在剩余时间内求所有物体对的最早
  TOI → 推进到该时刻 → 弹性响应（圆-圆等质量交换法向分量，圆-墙镜面
  反射）→ 继续，直到帧末。事件天然按时间升序输出。

### 精度与代价的取舍

- **解析求根 vs 细分求根**：圆/盒的 TOI 有闭式解，单次检测 O(1)、
  零迭代、零分配，误差仅来自浮点舍入（实测 ≤ 1.1e-15，见对拍）。
  细分/二分（保守推进）适用于任意凸形状，但要几十次迭代才能达到
  相近精度，且对“恰好相切”无符号变化、容易漏判——本库用判别式
  重根显式识别相切，避开该缺陷。
- **相切容差 `EPS = 1e-9`（相对）**：判别式与重叠量按问题尺度取相对
  容差。容差内一律判 `TOUCH`：宁可把“极浅穿透（深度 < ~1e-9·R）”
  归为擦边，也不让浮点噪声把擦边误判成碰撞。要更严格可调小 `EPS`，
  代价是构造数据中的数值噪声可能让相切实例落入 collide/miss。
- **同时刻事件**：`simulate` 用 1e-12 的绝对时间窗归并同一时刻的多个
  碰撞并逐个响应；已报告的擦边/重叠对在分离前不重复报告，避免死循环。

## 对拍数据（`python3 verify.py` 实测）

定点用例，扫掠解析 TOI vs 极小步长参考解（4096 步扫描 + 80 次二分）：

```
用例                          解析TOI        参考TOI       绝对误差   事件
静止+慢速接触              0.300000000000  0.300000000000  5.551e-17  collide
高速穿透(位移>>体长)        0.099000000000  0.099000000000  0.000e+00  collide
斜向擦撞                   0.317320513208  0.317320513208  0.000e+00  collide
追逐(同向差速)              0.750000000000  0.750000000000  0.000e+00  collide
恰好相切                   0.500000000000  0.499999997893  2.107e-09  touch
平行错过                            none           none          -    -
```

随机 2000 例对拍：碰撞 368 例全部一致，**TOI 最大绝对误差 1.110e-15**，
无误报、无漏检。（参考解自身精度约 1e-9，解析解反而更准。）

擦边接触三类判定（横向偏移 = 最近距离，R = 2）：

```
偏移 2.0000000  期望 touch    实得 touch    t=0.500000  [OK]  ← 相切：报告但不判碰撞
偏移 2.0000001  期望 none     实得 none               [OK]  ← 微偏外：不错报
偏移 1.9999999  期望 collide  实得 collide  t=0.499937  [OK]  ← 微偏内：不漏检
```

## 一帧内多次碰撞：事件序列（实测输出）

牛顿摆 A→B→C（dt=2s，动量沿链传递，A、B 停、C 以 1 运动）：

```
t=1.000000s  collide  球A <-> 球B
t=1.500000s  collide  球B <-> 球C
```

球在双墙间往返（dt=3s，两次反弹后速度复原）：

```
t=0.850000s  collide  球 <-> 右墙
t=2.550000s  collide  球 <-> 左墙
```
