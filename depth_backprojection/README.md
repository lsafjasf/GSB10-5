# 深度图反投影库（纯 Python 3 标准库）

将深度图按「针孔内参 + Brown-Conrady 畸变」模型反投影为三维点云，并附带
自测 / 对拍 / 对照 / 性能基准脚本。**内参与畸变必须一起使用**：畸变作用在
归一化平面上，漏掉畸变时越靠近视场边缘，反投影点整体偏移越大（见下文
对照数据，边缘可达 0.72 m @ ~2.4 m 深度）。

## 文件

- `backproject.py` — 库（相机模型、正投影、反投影、整图反投影）
- `selftest.py` — 自测、对拍、对照实验、百万像素基准
- `README.md` — 本说明

## 运行命令

```bash
cd depth_backprojection
python3 selftest.py        # 全部自测 + 对拍 + 对照 + 基准（约 20 s）
python3 -c "import backproject; help(backproject)"   # 查看 API
```

库用法：

```python
from backproject import CameraIntrinsics, Distortion, backproject_depthmap
cam  = CameraIntrinsics(fx=525, fy=525, cx=319.5, cy=239.5)
dist = Distortion(k1=-0.35, k2=0.15, p1=0.001, p2=-0.002, k3=-0.03)
points, stats = backproject_depthmap(cam, dist, 640, 480, depths)
# points: array('d')，行主序 (X,Y,Z)；缺失像素为 (NaN,NaN,NaN)
# stats:  {'valid': ..., 'missing': ..., 'total': ...}
```

## 相机模型

**内参（针孔）**：`fx, fy`（像素焦距），`cx, cy`（主点）。像素索引即像素
中心坐标。

**畸变（Brown-Conrady 5 参数，与 OpenCV 一致）**，作用于归一化平面
`(x, y) = (X/Z, Y/Z)`：

```
r2     = x^2 + y^2
radial = 1 + k1*r2 + k2*r2^2 + k3*r2^3
xd = x*radial + 2*p1*x*y + p2*(r2 + 2*x^2)
yd = y*radial + p1*(r2 + 2*y^2) + 2*p2*x*y
u  = fx*xd + cx
v  = fy*yd + cy
```

**反投影**（像素 `(u,v)` + 深度 `z`）：

```
xd = (u - cx)/fx,  yd = (v - cy)/fy
(x, y) = 畸变映射在 (xd, yd) 处的 Newton 反解（默认 5 次迭代）
P = (x*z, y*z, z)
```

Newton 反解使用解析雅可比，二次收敛：即使在 k1=-0.35 强畸变的图像角点，
5 次迭代残差也到机器精度（实测 ~5.6e-17）。对比普通不动点迭代在同样
位置 5 次后仍残留 ~7e-4（归一化坐标），因此选择 Newton。无畸变时走
`(x,y)=(xd,yd)` 直通路径，零迭代开销。

**取整处理**：亚像素投影值按 half-up 规则取整 `u_i = floor(u + 0.5)`。
最坏量化误差为 √2/2 像素，对应空间误差上界 `e ≤ z·(√2/2)/f`（f 为焦距、
z 为深度）。对拍数据中的整数像素误差均落在该界内。

**缺失深度**：`z <= 0` 或 `z` 为 NaN 的像素一律视为缺失（NaN 使 `z>0`
为 False，判断是确定性的）。缺失像素在稠密输出中**标记**为
`(NaN, NaN, NaN)` 并计入 `stats['missing']`，绝不静默反投影；稠密数组
行主序，下游可直接把 NaN 三元组当跳过掩码用。

## 对拍数据（已知三维点 → 投影 → 反投影）

相机 640×480，fx=fy=525，cx=319.5，cy=239.5；已知点覆盖整个视场（含四角
亚像素探针），深度 0.4–4 m。强畸变参数 k1=-0.35, k2=0.15, k3=-0.03,
p1=1e-3, p2=-2e-3。

| 情形 | 反投影方式 | mean (m) | RMSE (m) | max (m) |
|---|---|---|---|---|
| 无畸变 | 亚像素（模型反解误差） | 2.0e-17 | 6.0e-17 | 5.0e-16 |
| 无畸变 | 整数像素（含量化） | 1.19e-03 | 1.53e-03 | 4.76e-03 |
| 无畸变 | 量化上界 z·√2/2f | 2.32e-03 | 2.75e-03 | 5.34e-03 |
| 强畸变 | 亚像素（模型反解误差） | 9.6e-17 | 1.7e-16 | 9.2e-16 |
| 强畸变 | 整数像素（含量化） | 1.56e-03 | 1.97e-03 | 5.11e-03 |
| 强畸变 | 量化上界 z·√2/2f | 2.38e-03 | 2.81e-03 | 5.34e-03 |

分区（整数像素，强畸变）：中心 r<0.3 区域 max 4.0e-03 m；边缘 r>0.646
区域 max 5.1e-03 m；四角探针 max 2.2e-03 m。亚像素误差 ~1e-16 m 说明
正反投影严格互逆；整数像素误差全部来自取整量化且在上界之内。

## 有无畸变补偿对照（同一深度图，强畸变参数）

640×480 合成深度图（z≈2.0–3.3 m），分别用「完整模型」与「只用内参、
畸变置零（naive）」反投影，逐像素比较三维位移：

| 区域 | mean (m) | RMSE (m) | max (m) |
|---|---|---|---|
| 全图 | 0.108 | 0.154 | 0.719 |
| 中心 r<0.3 | 0.0094 | 0.0119 | 0.027 |
| 边缘 r>0.646 | 0.395 | 0.404 | 0.719 |

边缘/中心 RMSE 比 **33.9×**：漏掉畸变补偿时，视场边缘的点整体偏出约
0.4–0.7 m（深度仅 ~2.4 m），中心区影响约 1 cm。畸变补偿不可省略。

## 缺失深度处理结果

4×3 测试图（0 ×3、负值 ×1、NaN ×2、正常 ×6）：
`stats = {'valid': 6, 'missing': 6, 'total': 12}`；6 个缺失像素全部输出
`(NaN, NaN, NaN)`，6 个有效像素与单像素 API 结果逐一一致（<1e-12）。

## 百万像素性能（1000×1000，含 0.1% 缺失，强畸变，5 次 Newton 迭代）

| 指标 | 数值 |
|---|---|
| 耗时（3 次运行） | 13.70 s（含 tracemalloc 开销）/ 1.88 s / 1.90 s |
| 吞吐 | ~53 万像素/秒（纯 CPython，无 NumPy） |
| tracemalloc 峰值（调用期间） | 22.9 MiB（= 输出 array('d') 本身） |
| 进程 max RSS | 63.8 MiB（含解释器、输入 4 MiB、输出 24 MB） |
| 统计 | valid=999000, missing=1000 |

输出为紧凑 `array('d')`（3×1e6 双精度 = 22.9 MiB），输入 `array('f')`
仅 3.8 MiB，全程无逐点 Python 对象，内存峰值即输出数组量级。
