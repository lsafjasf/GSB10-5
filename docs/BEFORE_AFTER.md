# 泛化与抑制：处理前后风险对照

检查对象 `data/demo.csv`（12825 行），QI 组合
`age,gender,zipcode,occupation`，k = 5。

## 1. 泛化（generalization）

- `age`：精确年龄 → 10 岁年龄段（`age_band:10`，如 37 → 30-39）
- `zipcode`：6 位邮编 → 保留前 4 位（`zip_prefix:4`，如 310025 → 3100**）
- `occupation`：具体职业 → 职业大类（`occupation_category`，如 nurse → health）
- `gender`：保持原值（只有 2 个取值，泛化即删除，无必要）

| 指标 | 处理前（原始值） | 泛化后 |
|---|---:|---:|
| 等价类数 | 10685 | 102 |
| 最小类大小 | 1 | 1 |
| 唯一类（k=1） | 9452 | 3 |
| 唯一记录 | 9452 | 3 |
| 稀有类（k<5） | 10684 | 5 |
| 稀有记录 | 12025 | 8 |
| 最坏重识别概率 | 1.0 | 1.0 |
| 满足 k=5 | 否 | 否（残留 8 条） |
| 类大小直方图 | 1:9452, 2:1132, 3-4:100, 50+:1 | 1:3, 2:1, 3-4:1, 5-9:1, 10-49:24, 50+:72 |

泛化消除了 99.95% 的稀有类（10684 → 5），残留的是年龄/邮编本身就罕见、
泛化后仍无法凑够 5 人的极端记录（astronaut/matador 等），交给抑制处理。

## 2. 抑制（suppression），在泛化基础上

两种模式，结果都达到 k=5：

| 指标 | 抑制前 | drop（删除记录）后 | mask（QI 置 `*`）后 |
|---|---:|---:|---:|
| 记录数 | 12825 | 12817（删除 8） | 12825（置掩码 8） |
| 等价类数 | 102 | 97 | 98 |
| 最小类大小 | 1 | 8 | 8 |
| 唯一类 | 3 | 0 | 0 |
| 稀有类（k<5） | 5 | 0 | 0 |
| 稀有记录 | 8 | 0 | 0 |
| 最坏重识别概率 | 1.0 | 0.125 | 0.125 |
| 满足 k=5 | 否 | **是** | **是** |

数据代价：drop 损失 8/12825 = 0.062% 记录；mask 不丢记录但把 8 条记录的
QI 全部置 `*`。完整输出见 `out/suppress_drop.txt`、`out/suppress_mask.txt`。
