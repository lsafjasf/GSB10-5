# 10 万条译文占位符校验基准

> 由 `python3 -m benchmark.run --n 100000 --runs 3` 生成，随机种子 42。

## 环境

- Python: 3.12.3
- 平台: Linux-6.18.33.1-microsoft-standard-WSL2-x86_64-with-glibc2.39
- CPU: 16 核（基准为单线程）

## 数据构成

- 总量: 100000 条译文（命名 / 位置 / 裸占位符三种语法家族轮流）
- 场景: 顺序保持 30%、顺序调整 30%、缺失 10%、多余 10%、重复次数不一致 10%、非法 5%、格式漂移 5%
- 分类一致性核对: 不一致 0 条；格式漂移行 4900，strict 模式检出 4900
