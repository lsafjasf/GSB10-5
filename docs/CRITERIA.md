# 主体判据说明

仅使用 Python 3 标准库实现（无 NumPy / OpenCV / Pillow）。输入格式：PPM(P6/P5)、BMP(24/32 位无压缩)；输出：PPM/PGM。

## 1. 分析网格

直接逐像素计算 Sobel 对纯 Python 太慢，先对原图做**降采样分析网格**：

- 取步长 `step = ceil(max(W,H)/64)`，网格尺寸 `gw×gh`（默认上限 64 格）。
- 每格灰度 = 该格左上角像素灰度，再按 ITU-R 601 加权（`0.299R+0.587G+0.114B`，整数实现 `(77R+150G+29B)>>8`）。

降采样只用于「判据计算」，最终裁剪坐标全部映射回原图整数像素，裁剪结果从原图取像素，不经过降采样网格。

## 2. 三种主体线索（逐格，范围均归一到 [0,1]）

| 线索 | 定义 | 计算方式 |
|------|------|----------|
| 边缘密度 `edge` | Sobel 梯度幅值 | 网格上做 3×3 Sobel（gx, gy），`min(1, sqrt(gx²+gy²))`，灰度已除 255 |
| 局部对比度 `contrast` | 7×7 邻域灰度标准差 | 用灰度与灰度平方两张积分图（integral image）做常数时间窗口统计，`std/0.25` 截断到 1 |
| 显著性 `saliency` | 与整图平均灰度的偏离 | `min(1, |gray − mean(gray)| / 0.5)` |

融合得分（明确权重）：

```
score = 0.5 * edge + 0.3 * contrast + 0.2 * saliency
```

## 3. 热区阈值与连通域

- 阈值（自适应、确定）：`threshold = clamp(1.6 * mean(score), 0.06, 0.50)`。
  - 平坦图：`mean(score)≈0`，阈值取地板 0.06，但没有格子能超过它 → 无热区。
  - 噪声图：处处分高，阈值取天花板 0.50，仍然几乎处处过阈。
- `score >= threshold` 的格子构成二值热区，做一次 3×3 膨胀（把同一物体上被断开的边连起来）。
- 用**行程合并的 4 连通域算法**（每行用 Python 整数位掩码表示，连通合并用并查集）找出所有连通域，丢弃 <3 格的碎块，取最大连通域作为候选主体。

## 4. 主体置信度（明确公式）

对最大连通域计算：

- `area_fraction` = 连通域格数 / 网格总格数
- `compactness` = 连通域格数 / 其外接矩形格数（物体越接近实心矩形越高）
- `dominance` = 连通域格数 / 全部膨胀热区格数（最大连通域是否主导画面）
- `edge_density` = 连通域内 `edge` 均值

```
confidence = clamp( 0.35*compactness + 0.30*dominance
                  + 0.20*edge_density
                  + 0.15*min(1, area_fraction/0.02), 0, 1)
```

**接受条件（全部满足）**：

- `confidence >= 0.25`
- `0.002 <= area_fraction <= 0.55`

拒绝原因会明确记录在结果的 `reason` 字段：

- `no-hot-region`：没有任何热区（平坦/渐变）。
- `hot-region-fills-frame`：热区占网格 >55%，说明"主体"铺满整帧（典型如噪声/满屏纹理），不存在可定位的局部主体——这是噪声图的确定性判据，避免误判。
- `low-confidence`：聚集度/主导性/边缘不足。
- `subject-too-small`：小于网格 0.2%。

主体位置：外接矩形映射回像素后四周加 **8% 余量**并夹到图像边界；主体中心用连通域内 `score` 加权质心。

## 5. 裁剪框定位

目标整数尺寸 `(cw, ch)`：

1. 从受宽/高约束的最大候选开始枚举所有整数尺寸；
2. 在相对比例误差 `<= max(2%, 1.5×最优误差)` 的候选里选**面积最大**的——避免为了把比例误差从 0.1% 压到 0.01% 而选小一档、反而切掉主体；
3. 主体能完整放下（`sw<=cw 且 sh<=ch`）时，窗口以主体质心为中心，再向图像内夹紧（clamp）。因为窗口足够大，**贴边主体必然完整保留**。
4. 极端比例下窗口比主体还小（几何上不可能完整保留）：窗口尽量居中于质心并夹紧，保证质心落在框内、覆盖率最大，结果标记 `subject-larger-than-window`。

## 6. 找不到主体时的确定退路

`auto_crop(image, ratio, fallback=...)`：

- `fallback="center"`（默认）：输出严格居中的比例裁剪框（可复现）。
- `fallback="reject"`：拒绝裁剪，`mode="reject"`，CLI 退出码 2。

## 7. 越界校验

每个裁剪框都返回 `bounds_check`：

```
x>=0, y>=0, x+w<=img_w, y+h<=img_h, w>0, h>0
overflow_left/top/right/bottom_px  # 各方向越界像素数
all_inside                         # 全部条件的与
```

自测中 8 张图 × 7 种比例 = 56 个裁剪用例，`all_inside` 全部为 true。
