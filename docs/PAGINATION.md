# 页码口径说明

## 1. 物理页与逻辑页

| 概念 | 定义 | 编号方式 |
| --- | --- | --- |
| 物理页 (physical page) | 文档按阅读顺序逐张数下去的页，含前置内容与正文 | 从 1 开始连续不断 |
| 逻辑页 (logical page) | 实际印在页脚、并出现在目录里的页码 | 前置内容：小写罗马数字 i, ii, iii …；正文：阿拉伯数字 1, 2, 3 … 重新起算 |

换算规则（`tocgen.logical_label`）：

- 物理页 ≤ 前置页数 → 逻辑页 = 小写罗马数字（物理页 1 → `i`）；
- 物理页 > 前置页数 → 逻辑页 = 物理页 − 前置页数（正文首页恒为 `1`）；
- 无前置内容时两者完全一致（物理页 n = 逻辑页 n）。

## 2. 依据

- 前置/正文分编号是图书排版通行惯例（Chicago Manual of Style §1.4–1.6：
  front matter 用小写罗马数字，正文从 arabic 1 重新计页）。
- 工程上的关键收益：**目录本身放在前置内容里**。正文逻辑页恒从 1 起算，
  与前置内容页数无关，因此目录页数增减（增删条目导致目录变长）不会改变
  任何正文页码，目录一次生成即稳定，无需迭代重排。
- 目录项同时记录物理页（机器校验用）与逻辑页（展示用），两者由同一换算
  函数导出，保证口径唯一。

## 3. 标题换页与页码取值规则（确定性）

1. **章另起页**（`chapter_new_page=True`，默认）：一级标题即使当前页有空位
   也推到下一物理页顶部，页码取新页。
2. **keep-with-next**：标题后放不下 `keep_with_next`（默认 2）行正文时，
   整标题推到下一页，页码取新页。
3. **章末与章首同页**（`chapter_new_page=False`）：下一章章首可与上一章
   末尾同页，页码取**标题首行所在物理页**——即与上一章末同页同码。
   实测见 `out/4_mixed_levels_same_page.txt`：甲章末与乙章首同在物理页 1，
   两者目录页码均为 1。
4. **跨页超长标题**：页码取标题**首行**所在页（锚点在首行）。

## 4. 目录对齐规则

- 第 level 级缩进 `(level-1)*2` 列；
- 页码右对齐，右边缘固定在第 `width` 列，数字位宽取全部项最大值；
- 标题与页码之间点导引线填充，至少 2 个点；
- 超长标题按可用宽度折行，续行悬挂缩进与标题起始列对齐，页码只出现在
  条目最后一行——因此页码列对任何标题长度都不错位；
- 宽度按**显示列宽**计算（汉字等全角字符计 2 列），中英文混排不错位。

## 5. 校验方法

`tocgen.validate` 对每个目录项做两项独立核对：

1. **label_ok**：逻辑页码 == `logical_label(物理页, 前置页数)`；
2. **found_on_page**：标题首行确实出现在其声称的物理页内（逐行比对，
   并把匹配到的页内实际行作为证据输出）。

另做完整性检查：目录项数必须等于文档标题总数。
校验数据见 `out/*.txt` 的「逐项校验」一节。
