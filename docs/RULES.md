# 占位符校验规则与还原说明

本库（`phcheck`）面向 printf 风格的占位符（`%s`、`%(name)d`、`%2$.2f` 等），
只依赖 Python 3 标准库。核心结论：**译文里的占位符顺序可以变，但占位符集合（连同重复次数）必须和原文一致。**

## 1. 支持的占位符语法

```
%  [命名键]  [位置编号]  [标志]  [宽度]  [.精度]  [长度修饰]  转换字符

命名键   = (名字)              例：%(user)s
位置编号 = 数字$               例：%2$s（编号从 1 开始）
标志     = - + # 0 空格 的任意组合
宽度     = 数字
精度     = .数字
长度修饰 = h | hh | l | ll | L（仅解析，Python 渲染时忽略，不参与身份）
转换字符 = d i o u x X e E f F g G c r s a
```

另外：

- `%%` 是**普通百分号字面量**，不算占位符；`%5%`、`%(a)%` 等“带修饰的 `%%`”一律判非法。
- 一个字符串内三种寻址方式（命名 / 位置 / 裸占位符）**不可混用**，混用判 `invalid`。
- 不支持动态宽度/精度（`%*d`、`%.*f`），判 `invalid`。

## 2. 规范身份（canonical identity）

校验按“身份”的多重集进行，身份定义为**寻址键 + 转换字符**，与出现位置无关：

| 占位符 | 身份 |
| --- | --- |
| `%(user)s`、`%(user)10s` | `%(user)s` |
| `%2$d`、`%2$05d` | `%2$d` |
| `%d`、`%03d`、`%.2d` | `%d` |
| `%s`、`%.10s` | `%s` |

要点：

- 宽度、精度、标志、长度修饰**不参与身份**——调整宽度不判占位符缺失/多余。
- 转换字符参与身份：`%(count)d` 变成 `%(count)s` 会判“`%(count)d` 缺失 + `%(count)s` 多余”。
- 裸占位符 `%s` 的身份只有转换字符，不含名字；同一字符串里两个 `%s` 身份相同。

## 3. 多重集比对规则（顺序无关）

对原文、译文分别统计每个身份的出现次数，得到两个多重集（multiset），再逐身份比较：

| 情况 | 原文次数 | 译文次数 | 判定 |
| --- | --- | --- | --- |
| 一致 | n | n | 通过（顺序任意） |
| 缺失 missing | n ≥ 1 | 0 | 原文有、译文没有 |
| 多余 extra | 0 | n ≥ 1 | 译文有、原文没有 |
| 重复次数不一致 count_mismatch | n ≥ 1 | m ≥ 1，n ≠ m | 两边都有但次数不等，报告 `n -> m` |
| 非法 invalid | — | — | 任一侧含无法解析的占位符结构 |

**重复占位符计数规则**：同一个身份每出现一次计一次，不去重、不按序号区分（裸占位符没有名字，按转换字符计数）。
例如原文 `%(user)s … %(user)s` 中 `%(user)s` 计数为 2；译文只出现 1 次即报 `count_mismatch: 2 -> 1`。
`%s %s` 与 `%s` 比较报 `%s: 2 -> 1`。

一条译文可以同时命中多个分类（如转换字符被改：missing + extra；非法占位符旁边还少了一个正常占位符：invalid + missing），各分类全部列出。
`ok = 没有 missing / extra / count_mismatch / invalid`。

### invalid 的具体情形

- 未知转换字符，如 `%z`
- 悬空 `%`（结尾单独的 `%`、`%.2` 这类结构不完整序列）
- 动态宽度/精度 `*`
- 空命名键 `%()s`
- 位置编号为 0（`%0$s`）或命名与位置同体（`%(a)1$s`）
- 同一字符串混用寻址方式（`%(a)s %1$s`、`%s %1$d`）
- 带修饰的 `%%`（`%5%`）

非法片段逐条上报，扫描不会在第一个错误处中断。

### 格式漂移 format_drift（可选）

`validate(src, tgt, strict_format=True)` 时，身份与次数都一致、但宽度/精度/标志/长度不同，会额外列入 `format_drift`
（**不影响 ok**，只是提示，例如 `%05d` 被改成 `%5d`，渲染结果的补零会变，属于需要人工确认的语义变化）。默认关闭。

## 4. 还原（取值映射）规则

`restore(source, translation, values)` 按译文的结构输出，取值按占位符身份分发：

- 命名占位符 `%(name)c` → `values[name]`（`values` 为 dict 等 Mapping）；乱序、多次出现都取同一个值。
- 位置占位符 `%n$c` → 第 `n` 个值（序列下标 `n-1`；Mapping 时支持 `n` 或 `"n"` 键）；与译文里的先后顺序无关，重排安全。
- 裸占位符 `%c` → 译文中第 `k` 个裸占位符取第 `k` 个值（与运行时按顺序消费参数的行为一致）。
- `%%` → 输出单个 `%`。

单 token 的格式化去掉命名键/位置编号/长度修饰后直接走 Python 原生 `%`（如 `%2$08.2f` 等价于 `%08.2f`），
所以宽度、精度、标志、进制（`%x`/`%o`）、字符串截断（`%.3s`）的行为与原生完全一致。

`check=True`（默认）时先跑多重集校验，不通过直接抛 `RenderError`；取值缺失或类型不符同样抛 `RenderError`。

### 裸占位符重排风险（重要）

裸占位符靠顺序取值。`%s 等于 %d` 译成 `%d = %s` 时集合一致、**校验通过**，但运行时第 1 个字符串值会被塞进 `%d`，
可能格式化失败或错位。这不是校验器能静态阻断的（集合确实一致）。**需要重排的译文应使用命名参数或 `%n$` 位置参数。**

## 5. 对拍与边界用例

- `fixtures/validation_cases.json`：23 组校验对拍，覆盖顺序调整、缺失、多余、重复次数不一致、
  转换字符被改、`%%` 字面量、各类 invalid、strict 格式漂移。
- `fixtures/restore_cases.json`：8 组还原对拍（含原文/译文/取值/期望输出）；
  测试中对非位置参数的用例额外与 Python 原生 `%` 交叉比对，必须完全一致。
- 边界用例在 `tests/` 中：空精度 `%.f`、长度修饰 `%lld`、多非法片段逐条上报、dict 形式传位置参数、
  取值缺失/类型不符报错、混用寻址等。

## 7. API 速览

```python
from phcheck import validate, restore

report = validate("你好 %(name)s", "%(name)s hello")
report.ok                 # True
report.missing            # []
report.extra              # []
report.count_mismatch     # []
report.invalid            # []
report.as_dict()          # JSON 可序列化的完整报告

restore("你好 %(name)s", "%(name)s hello", {"name": "Ada"})  # 'Ada hello'
```
