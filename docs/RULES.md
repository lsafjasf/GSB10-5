# 文献引用编号重排规则说明

## 1. 编号规则

1. **引用标记**：正文中形如 `[n]`、`[n,m]`、`[n-m]` 的方括号（n、m 为十进制正整数，
   逗号/连字符两侧允许空格），括号内只允许数字、逗号、连字符、空格，其余方括号不视为引用。
2. **首次出现为准**：正文从左到右扫描；同一方括号内按从左到右展开
   （区间 `n-m` 展开为 `n, n+1, …, m`）。每个被引用的条目编号按其**在正文中的
   首次出现顺序**依次分配新编号 1, 2, 3, …。
3. **重复引用只占一个编号**：同一条目编号再次出现时，沿用首次分配的新编号，
   不占用新编号。例如 `[3] … [1,5] … [3]` 中 3 的两处引用都改为同一个新编号 1。
4. **文末列表重排**：参考文献列表按新编号升序重写，**只保留被引用过的条目**，
   条目文本本身逐字节不变。
5. **悬空引用（引用了不存在的条目）**：该处标记**原样保留不改写**，并分类报告。
6. **回写不改变正文内容**：除引用标记方括号内部外，正文逐字节不变；标记内数字
   替换为新编号，数字间的分隔符（逗号/连字符及两侧空格）原样保留。区间标记展开后
   若新编号不再连续，连字符降级为逗号列表以保证语义正确（如 `[1-3]` → `[1,3,2]`）。

## 2. 分类报告

| 类别 | 字段 | 含义 |
|---|---|---|
| 悬空引用 | `issues.dangling_citations` | 正文引用但文末列表中不存在的编号 |
| 孤立条目 | `issues.orphan_entries` | 列表中存在但从未被引用的条目编号（重排后移除） |
| 编号跳号 | `issues.numbering_gaps_in_old_list` | 旧列表编号区间内缺失的整数 |

## 3. 样例重排对照表（sample.md → sample_renumbered.md）

| 旧编号 | 新编号 | 条目 | 首次出现位置 |
|---|---|---|---|
| 3 | 1 | 王五. 基础理论 | 正文第 1 个引用点 `[3]` |
| 1 | 2 | 张三. 某方法研究 | 第 2 个引用点 `[1,5]` |
| 5 | 3 | 赵六. 推广工作 | 第 2 个引用点 `[1,5]` |
| 7 | 4 | 钱七. 实验一 | 第 3 个引用点 `[7-8]` |
| 8 | 5 | 孙八. 实验二 | 第 3 个引用点 `[7-8]` |
| 2 | —（孤立条目，移除） | 李四. 从未被引用的孤立条目 | 从未被引用 |
| 9 | —（悬空引用，原样保留） | 列表中不存在 | 第 5 个引用点 `[9]` |

旧列表跳号：4、6。正文中 `[3]` 共出现 2 次、`[5,3]` 中再次出现，均只占新编号 1/3。

## 4. 回写后一致性校验数据（sample_report.json）

| 校验项 | 结果 | 说明 |
|---|---|---|
| `new_ids_contiguous_1_to_N` | 通过 | 新正文引用编号为 1..5 连续无跳号 |
| `first_appearance_order` | 通过 | 新编号按首次出现顺序分配 |
| `cited_count_matches_list` | 通过 | 正文被引条目数(5) == 文末条目数(5) |
| `rewrite_reconstruction` | 通过 | 由替换记录重建的正文与实际输出逐字节一致 |
| `marker_count_preserved` | 通过 | 重写前后标记数一致（6，含原样保留的悬空引用） |
| `brackets_balanced` | 通过 | 方括号配平 |

## 5. 重排前后正文逐字节对比

`byte_compare.body_identical_outside_markers = true`：把每个被改写的标记段视为
允许变更窗口，**窗口之外正文逐字节相同**。样例中共 5 个标记段被改写
（`[3]→[1]`、`[1,5]→[2,3]`、`[7-8]→[4-5]`、`[3]→[1]`、`[5,3]→[3,1]`），
每处变更的旧/新字节与偏移量记录在 `sample_report.json` 的 `byte_compare.diffs` 中。

## 6. 性能数据（10 万个引用点，benchmark.py）

测试文档：100,000 个引用点（60% 单条、25% 组合、15% 区间），2,000 个条目，5.20 MB。
环境：Python 3.12.3，Linux x86_64。

| 指标 | 数值 |
|---|---|
| 重排+校验耗时（无追踪） | ≈ 1.36 s |
| 重排+校验耗时（tracemalloc 开启） | ≈ 6.95 s |
| 内存峰值（tracemalloc Python 堆） | ≈ 145.6 MB |
| 内存峰值（进程 RSS） | ≈ 491 MB |

## 7. 运行命令

```bash
# 重排（输出文档 + JSON 报告）
python3 refrenum.py sample.md -o sample_renumbered.md -r sample_report.json

# 自测（16 个用例：单条/重复/孤立/跳号/悬空/区间/逐字节/幂等等）
python3 test_refrenum.py -v

# 基准（默认 10 万引用点，可传自定义数量）
python3 benchmark.py [引用点数]
```
