# 产品手册

本手册介绍产品的基本用法。

## 快速上手 {#quickstart}

快速开始章节包含安装与第一个示例。
安装命令为 pip install product。
运行命令为 product demo。
示例代码位于 demo 目录。
请确认 Python 版本为 3.10 或更高。

### 安装环境

安装环境前先检查操作系统版本。
Windows 用户使用安装包。
macOS 用户使用 brew。
Linux 用户使用发行版包管理器。
安装完成后运行 product --version 验证。

### 第一个示例

第一个示例展示如何创建项目。
执行 product init my-project。
进入目录 cd my-project。
运行 product run 启动服务。
浏览器打开 http://localhost:8080。

## 核心概念 {#concepts}

核心概念章节解释领域模型。
产品由项目、模块和任务三种实体组成。
项目包含多个模块。
模块包含多个任务。
任务是最小执行单元。

### 项目

项目是顶层资源。
每个项目有唯一名称。
项目有独立的配置文件。
项目可以被归档。
项目可以被删除。

### 模块

模块是可复用的功能集合。
模块有输入与输出定义。
模块之间可以建立依赖。
模块支持版本号。
模块可以发布到仓库。

## API 参考 {#api}

API 参考章节列出全部接口。
接口分为同步与异步两类。
所有接口都返回 JSON。
错误码统一在附录定义。
鉴权使用 Bearer Token。

### 数据接口

数据接口负责增删改查。
列表接口支持分页参数。
详情接口返回完整字段。
创建接口需要写权限。
删除接口为软删除。
部分场景下列表接口的总数字段存在精度问题，需要客户端自行统计。

### 认证接口

认证接口用于获取令牌。
调用 /auth/login 传入用户名密码。
令牌有效期为两小时。
刷新令牌调用 /auth/refresh。
登出调用 /auth/logout。

## 高级配置 {#advanced}

高级配置章节介绍生产环境参数。
线程池大小默认十六。
连接超时默认五秒。
重试次数默认三次。
日志级别默认 INFO。

### 任务

任务是最小的执行单元实体。
任务从属于某个模块。
任务有优先级字段。
任务可以被暂停与恢复。
任务执行会产生运行日志。

### 生产部署

生产部署章节描述上线流程。
先在预发布环境回归。
灰度比例从百分之十开始。
观察错误率与延迟指标。
确认无异常后全量发布。
上线后保留一小时值守。

#### 容器化部署

容器镜像基于精简基础系统构建。
启动命令由入口脚本包装。
健康检查访问 /health 端点。
资源限制建议两核四吉。
日志输出到标准输出。

### 日志配置

日志按天滚动并自动压缩。
保留天数默认三十天。
敏感字段自动脱敏。
错误日志单独采集。
日志格式为结构化 JSON。
