# 脚注编号与跨页合并 —— 运行报告

环境: Python 3.12.3（仅标准库）

## 1. 编号对照表（重复引用共享编号）

编号按 key 的**首次引用点**在全文中的顺序分配；同一 key 的重复引用共享同一编号。

| 编号 | 脚注 key | 引用点 seq（全文顺序） | 引用位置 |
|---|---|---|---|
| 1 | src | #1, #3, #4, #5 | p1.L1, p1.L3, p1.L4, p1.L4 |
| 2 | auth | #2 | p1.L2 |
| 3 | see | #6 | p2.L5 |
| 4 | note | #7 | p2.L6 |
| 5 | long | #8 | p2.L7 |

共 8 个引用点，5 个编号 —— 重复引用不另占编号。

## 4. 引用一致性校验

- 删除前: 8 个引用点 / 5 个编号 → **全部通过**（每个引用点都能指回同一编号，无空号，跨页块连续）
- 删除后: 6 个引用点 / 4 个编号 → **全部通过**（每个引用点都能指回同一编号，无空号，跨页块连续）

逐点校验明细（删除前）：

| 引用点 seq | key | 正文编号 | 页脚条目编号 | 回链包含该点 |
|---|---|---|---|---|
| #1 | src | 1 | 1 | ✓ |
| #2 | auth | 2 | 2 | ✓ |
| #3 | src | 1 | 1 | ✓ |
| #4 | src | 1 | 1 | ✓ |
| #5 | src | 1 | 1 | ✓ |
| #6 | see | 3 | 3 | ✓ |
| #7 | note | 4 | 4 | ✓ |
| #8 | long | 5 | 5 | ✓ |

## 5. 性能：50,000 个引用点

- 引用点: 50000，脚注定义: 4000，正文行: 25001
- 结果: 626 页，4000 个编号，一致性校验 通过
- 耗时: **227.2 ms**（编号 + 分页 + 页脚排版）
- 内存峰值（tracemalloc）: **24.6 MiB**；进程 RSS 峰值: 109.6 MiB
