# 色调曲线映射（Python 3，仅标准库）

## 运行命令

```bash
cd tonecurve
python3 selftest.py        # 全部自测 + 1 万张图性能测试
```

库文件：`tonecurve.py`；自测：`selftest.py`。无第三方依赖，Python ≥ 3.7。

## 曲线构造说明

- **输入**：控制点列表 `[(x, y), ...]`，x/y ∈ [0, 255]，允许浮点。
- **归一化**：按 x 升序排序；相同 x 的 y 取平均合并。
- **端点处理**：强制钉住端点 `(0,0)` 与 `(255,255)`——用户给的端点 y 值被覆盖并记录，未给端点则自动补齐并记录。保证零点→零点、满值→满值。
- **越界处理**：y 超出 [0,255] 的控制点先记录，再钳制回边界。
- **插值方法**：相邻控制点间**分段线性插值**（piecewise linear），铺满 0..255 共 256 项。不引入样条，避免过冲/振荡。
- **单调性校验与修正（两级）**：
  1. 浮点级：对控制点逐段检查斜率是否非负；存在下降段时用 **PAVA 保序回归**（等权）把 y 修正为非递减序列（L2 意义下改动最小），修正点逐一报告。
  2. 整数级：四舍五入（half-up）成整数 LUT 后再做前缀 cummax 扫描，消除量化引入的微小下降，保证最终 LUT 严格非递减。
- **映射**：`apply_lut` 用 `bytes.translate` 整图查表（生产路径）；`map_pointwise` 逐像素二分 + 分段线性插值（独立参考实现，用于对拍）。

## 单调性校验结果（实测输出）

| 用例 | 原始控制点 | 处理 | 最终 LUT |
|---|---|---|---|
| 线性（恒等） | 单调不减 | 无需修正 | 单调不减，反转对数=0 |
| 强对比 S 曲线 | 单调不减 | 无需修正 | 单调不减，反转对数=0 |
| 非单调控制点 `(64,120)→(128,90)` | **非单调**，检出下降段 | PAVA 修正 2 点：120→105、90→105 | 单调不减，反转对数=0 |
| 端点越界 `(0,40)`、`(255,300)` | 单调不减 | 端点覆盖为 (0,0)、(255,255) | 单调不减，反转对数=0 |
| 内部越界+非单调 `(60,280)`、`(128,50)`、`(200,260)` | **非单调** + 2 点越界 | 钳制 280→255、260→255；PAVA 修正 255→152.5、50→152.5 | 单调不减，反转对数=0 |

## 端点边界结果

5 个用例最终 LUT 均满足 `LUT[0]=0`、`LUT[255]=255`（自测中有断言，全部 PASS）。

## 对拍数据（LUT 查表 vs 逐点插值）

每例用 64×64×3 随机图 + 全 256 灰阶图，共 12544 像素：

| 用例 | 不一致像素 | 最大绝对差 |
|---|---|---|
| 线性 | 0 | 0 |
| 强对比 S | 0 | 0 |
| 非单调（修正后） | 0 | 0 |
| 端点越界（修正后） | 0 | 0 |
| 越界+非单调组合 | 0 | 0 |

容差设为 ≤1（仅允许四舍五入量化差），实测全部为 0。

## 1 万张图性能（本机实测，Python 3.12.3）

- 规模：10000 张 256×256×3 图，共 19.66 亿像素（1966 MP）
- 总耗时：**0.602 s**；单张均值 **0.060 ms**；吞吐 **16607 张/s（3265 MP/s）**
- Python 堆内存峰值（tracemalloc，映射过程分配）：**0.39 MB**
- 进程 RSS 峰值（ru_maxrss，含 1 万张输入图常驻 ≈1.83 GB）：**1889 MB**——映射本身近似零额外内存，逐张流式处理时内存与图数无关
